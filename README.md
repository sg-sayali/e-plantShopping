# e-plantShopping

## Project Description
Paradise Nursery is a React-based plant shopping application where users can browse plants by category and manage their shopping cart.

## Features
- Browse plants in three categories.
- View plant images, names, and prices.
- Add plants to the shopping cart.
- Increase or decrease item quantities.
- Remove plants from the cart.
- View item subtotals and the cart total.
- Continue shopping or view the checkout placeholder.

## Technologies
- React
- Vite
- Redux Toolkit
- React Redux
- CSS

## Run Locally
1. Install dependencies: `npm install`
2. Start the app: `npm run dev`
3. Build for production: `npm run build`
